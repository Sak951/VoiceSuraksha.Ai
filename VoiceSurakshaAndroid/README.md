# VoiceSuraksha.Ai Android
Read-only client. Fetches /api/v1/live and /api/v1/call from the server and draws the verdict over the call screen.
1. Android Studio -> Open this folder -> let Gradle sync (it creates the wrapper) -> Run on phone.
2. In app: Allow overlay + Allow phone state. Tap "Test overlay".
3. Server URL defaults to https://choking-justify-plot.ngrok-free.dev (editable in app).
4. Change Human/AI from the server control page. Overlay follows live on every call.
Xiaomi/Oppo/Vivo: also enable "Display pop-up windows while running in background" + Autostart in app settings.
